# Narrativa

El aprendizaje de la programación suele estar desconectado de las herramientas reales que utilizan los desarrolladores en la industria. Los estudiantes aprenden a escribir código, pero rara vez se les enseña el ciclo de vida del software: control de versiones, integración continua (CI/CD) y revisión de código (Pull Requests). 

Esta plataforma nace para cerrar esa brecha. Al utilizar GitHub como el motor principal de entrega y evaluación, los estudiantes no solo aprenden lógica de programación en lenguajes como Java, Python, C o GDScript, sino que asimilan de forma natural el flujo de trabajo profesional. El código no se entrega en un `.zip`, se entrega mediante un *Push* y se evalúa mediante automatización.
