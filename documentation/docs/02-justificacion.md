# Justificación

Los Learning Management Systems (LMS) tradicionales (como Moodle o Canvas) son deficientes para la enseñanza técnica avanzada. Carecen de editores de código con autocompletado real, no pueden ejecutar código en el navegador y no soportan flujos asíncronos complejos como compilar una app móvil (Expo) o testear un videojuego (Godot). 

Por otro lado, configurar esta infraestructura desde cero para cada profesor es una pesadilla técnica. Se requiere una solución construida en tecnologías web modernas (TypeScript, Nest.js para el backend y Next.js para el frontend) que orqueste estos servicios (GitHub Actions, Judge0) de manera transparente para el alumno y el profesor, centralizando la evaluación y el feedback.
